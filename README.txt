GAURAV TRAVEL — PREMIUM HOME SCREEN / INSTALL UPDATE

Includes: premium black-and-gold car logo icons (192 and 512), web manifest, service worker, and install button that opens the native browser install prompt when Chrome provides it.

HOW TO UPDATE NETLIFY FROM PHONE:
1. Extract this ZIP.
2. Upload ALL files and folders inside gaurav_install_update to your Netlify site's deploy/upload area, keeping the folder structure (index.html, manifest.webmanifest, sw.js, icons/). Do not upload only index.html.
3. Open the site's public HTTPS URL ending in netlify.app in Chrome, not the Netlify dashboard or embedded preview.
4. Refresh the public site, tap Install App. If Chrome does not show the native prompt, use Chrome ⋮ > Install app / Add to Home screen.

Important: browsers decide whether to show direct install prompts; a website button cannot force-install an APK. For an installable PWA, keep the manifest, service worker, and icons at the same site root.
